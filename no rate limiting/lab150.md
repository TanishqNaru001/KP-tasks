# Missing Rate Limiting on Adding Comments - Redditgifts

**Target:** `https://hackarena.site/subdomains/load/index.php#comments-anchor`
**Vulnerability Class:** Missing Rate Limiting / Resource Exhaustion (CWE-307)
**Severity:** Low–Medium
**Bypass Technique:** Payload fuzzing on the `comment` field via Burp Intruder — no throttling on repeated submissions

## Description

The comment submission feature does not enforce any rate limiting. The comment request was sent to Burp Intruder with the payload position set on the comment body field. Repeated requests were submitted in rapid succession, and all were accepted with no cooldown, CAPTCHA, or blocking.

## Steps to Reproduce

1. Submit a comment and intercept the request in Burp Suite
2. Send the request to Intruder, set payload position on the `comment` field
3. Load a simple payload list and start the attack
4. Observe repeated comment submissions succeed with no throttling

## Impact

- Enables comment spam/flooding, degrading content quality and user experience
- Can be scripted to mass-post malicious links or abusive content at scale
- Backend resource exhaustion from unrestricted write operations

## Remediation

- Rate-limit comment submissions per user/session/IP (e.g. 1 per few seconds, capped per minute)
- Add CAPTCHA after a small number of rapid submissions
- Return `429 Too Many Requests` once threshold is exceeded
- Implement server-side spam detection for duplicate/rapid-fire content
