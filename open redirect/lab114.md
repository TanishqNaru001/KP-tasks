# Open Redirect via `redirect` Parameter

**Target:** `https://kzlabs.in/subdomains/redirect/`


## Description

The endpoint `https://kzlabs.in/subdomains/redirect/` accepts a user-controlled URL in the "URL shorten" field and redirects the browser to that URL without validating it against a whitelist of trusted domains.

## Steps to Reproduce

1. Navigate to `https://kzlabs.in/subdomains/redirect/`
2. In the URL shorten field, enter `https://www.bing.com`
3. Submit / hit Enter
4. Observe the browser is redirected to `bing.com` instead of staying within the app or showing an interstitial warning

## Impact

- Can be abused for **phishing** - an attacker sends a link that appears to belong to `kzlabs.in` but lands the victim on an attacker-controlled page
- Can bypass email/URL filters that trust the `kzlabs.in` domain
- If any auth tokens are passed in the URL fragment/query during this flow, could enable **token leakage**

## Remediation

- Validate the target URL against an allowlist of permitted domains
- If open redirection is a required feature (e.g., a legitimate shortener), add an interstitial "You are leaving kzlabs.in" warning page
- Reject relative-scheme or protocol-relative URLs (`//evil.com`), not just `http(s)://` ones
