# Open Redirect - Omise

**Target:** `https://kzlabs.in/subdomains/links/index.php?category=developers&page=1`
**Vulnerability Class:** Open Redirect (CWE-601)
**Severity:** Low–Medium
**Bypass Technique:** Multiple/mixed slashes (`////bing.com`) to defeat naive prefix/scheme validation

## Description

The `index.php` page under `/subdomains/links/` lists developer-category links. One of the outbound links (labeled/associated with **Omise**) can be manipulated by appending extra slashes followed by an external domain, causing the browser to be redirected off-site. This suggests the redirect handler only checks for a leading `http(s)://` or a specific path prefix, and doesn't properly canonicalize the URL before validating it - so `////bing.com` is interpreted by the browser as protocol-relative and resolves to `https://bing.com`.

## Steps to Reproduce

1. Navigate to:
   `https://kzlabs.in/subdomains/links/index.php?category=developers&page=1`
2. Locate the **Omise** link/entry on the page
3. Append `////bing.com` to the link's path (as shown below)
4. Load the crafted URL in a browser
5. Observe the browser redirects to `bing.com` instead of the intended Omise destination

## Impact

- **Phishing:** attacker-crafted links appear to originate from `kzlabs.in` (a trusted domain in this context) but land the victim on an attacker-controlled page
- **Filter bypass:** naive validation that checks only for a string prefix (`http://`, `https://`) or a fixed number of leading slashes can be defeated with variations like `////`, `\/\/`, or mixed encoding
- **Trust abuse:** if this domain/link listing is used in outbound communications (newsletters, partner integrations, etc.), the redirect could be weaponized in a targeted phishing campaign against users expecting to reach Omise

## Remediation

- Canonicalize and fully parse the URL (not just prefix-match) before deciding whether it's internal or external
- Validate the final resolved host against an allowlist of trusted domains
- Explicitly reject protocol-relative URLs (`//`, `///`, `////`, etc.) and encoded variants (`%2F%2F`)
- Add an interstitial "You are leaving kzlabs.in" confirmation page for any redirect to an external host
