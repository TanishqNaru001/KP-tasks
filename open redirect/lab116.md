# Open Redirect - Semrush

**Target:** `https://kzlabs.in/subdomains/out/`
**Vulnerability Class:** Open Redirect (CWE-601)
**Severity:** Low–Medium

## Description

The `/subdomains/out/` endpoint is used as an outbound link redirector - for example, under the "keyword ranking" section, links pointing to Semrush pass through this redirector via a `url` query parameter. The parameter accepts any URL-encoded destination and redirects the browser to it without validating the target against an allowlist of trusted/expected domains (e.g. `semrush.com`).

## Steps to Reproduce

1. On `https://kzlabs.in/subdomains/out/`, locate a redirect link under the keyword ranking section, e.g.:
   ```
   https://kzlabs.in/subdomains/out/?url=https%3A%2F%2Fwww.semrush.com%2Ffeatures%2F
   ```
2. Replace the `url` parameter value with an arbitrary external URL (URL-encoded), e.g.:
   ```
   https://kzlabs.in/subdomains/out/?url=https%3A%2F%2Fwww.bing.com
   ```
3. Load the crafted URL in a browser
4. Observe the browser redirects to `bing.com` instead of the expected `semrush.com` destination

## Impact

- **Phishing:** attacker-crafted links using the trusted `kzlabs.in` domain can redirect victims to attacker-controlled pages
- **Filter/reputation bypass:** links shared in emails, ads, or reports that appear to point to `kzlabs.in` (or its intended target, e.g. Semrush) can be repurposed to reach any destination
- **Brand abuse:** the redirector is presumably meant to track/relay clicks to legitimate partner pages (Semrush, etc.); this trust can be exploited for social-engineering campaigns impersonating those partners

## Remediation

- Validate the `url` parameter's resolved host against an allowlist of expected/partner domains (e.g. `semrush.com` and other legitimate outbound targets) before redirecting
- Reject or sanitize arbitrary external URLs that don't match the allowlist
- Add an interstitial "You are leaving kzlabs.in" confirmation page for any redirect to an external host
- Consider signing/tokenizing redirect URLs server-side so only pre-approved links can be used with this endpoint
